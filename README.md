# 질문에서 결과물까지 · 강사용 교안

이성엽의 에이전트 AI 연수 「질문에서 결과물까지」의 강사용 교안과 발표 화면입니다.

강의는 조각 다섯 개입니다: **돌아보기 · 개론 · 1회기(이미지 · 수업설계) · 2회기(행정 · 바이브코딩) · 마무리(개인정보)**. [첫 화면](https://iepon.site/리빙)에서 그날 순서를 고르면 고른 조각이 한 강의로 이어집니다. 중간에 교안을 바꾸거나 TV 연결 코드를 다시 만들지 않습니다.

| 바로가기 | 순서 | 주소 |
| --- | --- | --- |
| 1회차 | 개론 → 1회기 | `living/교안.html?set=intro,s1` |
| 2회차 · 이어서 | 돌아보기 → 2회기 → 마무리 | `living/교안.html?set=recap,s2,end` |
| 2회차만 하는 날 | 개론 → 2회기 → 마무리 | `living/교안.html?set=intro,s2,end` |
| 하루에 모두 | 개론 → 1회기 → 2회기 → 마무리 | `living/교안.html?set=intro,s1,s2,end` |

주소 끝에 `&prompter=1`을 붙이면 프롬프터, `index.html?set=…&tv=1`은 노트북 · TV 화면입니다. **TV 쪽도 같은 순서**로 열어야 연결됩니다(프롬프터의 ‘TV 주소 복사’ 주소에는 순서가 들어 있습니다).

## 프롬프터와 TV 발표

대본 영역에서 왼쪽으로 밀면 다음 장, 오른쪽으로 밀면 이전 장입니다. 오른쪽 가장자리를 두 번 탭하면 다음, 왼쪽 가장자리는 이전입니다. 세로로 움직이면 대본만 스크롤됩니다. 카드 화면에서는 강의 장이 바뀌지 않습니다. 손짓 조작은 **설정**에서 끌 수 있습니다.


첫 화면에서 **프롬프터**를 누르면 큰 대본과 간결한 조작 줄이 나옵니다. 글자 크기(24~64px), 슬라이드 미리보기, 자동 스크롤 속도와 TV 연결은 **설정**에서 조절합니다. 직접 스크롤하거나 장을 바꾸면 자동 스크롤은 멈춥니다. 화면 잠금 방지는 지원하는 브라우저에서만 작동합니다.

- **노트북 한 대 + TV:** 화면을 복제하지 말고 디스플레이를 **확장**으로 설정합니다. 프롬프터의 **설정 → TV 연결 → 슬라이드 창 열기**를 눌러 그 창만 TV로 옮기고 전체 화면으로 엽니다. 교안과 프롬프터는 노트북에 둡니다. 같은 기기의 창 연결은 인터넷 없이도 작동하지만 페이지와 자료는 미리 불러오거나 로컬 사본을 열어야 합니다.
- **태블릿 + Windows 데스크톱/노트북 + TV:** 태블릿에서 **프롬프터 → 설정 → TV 연결 → 연결 코드 만들기**를 누릅니다. **코드 준비 완료**가 나오면 Windows 컴퓨터에서 같은 강의의 **TV 연결 화면**을 열어 10자리 코드를 입력하거나, **TV 주소 복사**로 얻은 주소를 엽니다. 컴퓨터와 TV를 HDMI 등으로 연결하고 TV에서 **전체 화면**을 누릅니다. 컴퓨터 모니터와 TV를 따로 쓰려면 Windows에서 **Win+P → 확장**을 선택한 뒤 슬라이드 창을 TV로 옮깁니다. 태블릿에는 강사 화면을 열어 둔 채 이전·다음으로 넘깁니다. TV 쪽에서는 장을 바꾸지 못합니다.
- **아이패드 프로 12.9인치 가로 + 노트북 HDMI:** 아이패드는 프롬프터, 노트북은 TV 화면을 엽니다. 대본은 아이패드에만 있으므로 노트북 화면을 TV에 복제해도 됩니다. 노트북에 다른 작업 화면도 필요하면 확장으로 설정하고 슬라이드 창만 TV로 옮깁니다.
- **기다릴 때 카드:** 프롬프터의 대기 카드 버튼으로 같은 페이지에서 엽니다. 지금 모듈과 공통 카드를 먼저 보고, 모듈·길이·검색으로 고를 수 있습니다. TV에는 원래 장이 유지됩니다. ‘대본으로 돌아가기’를 누르면 읽던 위치로 돌아옵니다.
- **고른 순서 전체를 한 번 연결합니다.** 조각이 바뀌는 곳도 같은 강의입니다. 강사 화면을 새로 열거나 연결을 종료했다면 새 코드로 다시 연결합니다. TV 화면만 새로 고친 경우 주소의 코드로 재연결합니다.

두 기기는 HTTPS 연결 서버를 통해 현재 장을 맞춥니다. 같은 와이파이를 사용할 필요는 없으며 태블릿의 모바일 인터넷과 Windows 컴퓨터의 유선 인터넷처럼 서로 다른 망에서도 각각 서버에 접속할 수 있으면 연결됩니다. 두 기기 모두 인터넷과 최신 브라우저가 필요합니다. 학교의 접속 제한이나 서버 장애가 있으면 위의 **노트북 한 대 + TV 확장 화면**을 사용할 수 있습니다.

TV는 이전 응답을 받은 뒤 약 **700ms** 간격으로 현재 장을 확인합니다. 네트워크 응답 시간에 따라 실제 반영은 더 늦을 수 있습니다. 강사 화면은 장이 바뀔 때 바로 갱신하고, 이동이 없어도 5초마다 연결을 유지합니다. 잠시 끊겼을 때는 마지막 슬라이드를 유지하며 자동으로 재시도합니다. 연결이 돌아오면 중간에 넘긴 장을 차례로 재생하지 않고 **현재 장**으로 맞춥니다. **다시 연결** 버튼을 누르거나 강사 화면으로 돌아와도 연결을 다시 시도합니다.

로그인 없이 임의의 연결 코드를 사용합니다. 코드를 아는 기기는 현재 슬라이드를 볼 수 있습니다. 강사 화면은 별도의 임의 쓰기 토큰을 만들어 브라우저 메모리에 보관하며, TV 주소와 연결 코드에는 넣지 않습니다. TV는 코드를 알아도 장을 변경하거나 강사의 연결을 종료할 권한이 없습니다. 연결 서버가 다루는 발표 정보는 강의 식별자·전체 장수·현재 장 번호·순서 번호·접속 시각이며 대본이나 강사용 근거를 보내지 않습니다. 카메라·마이크 권한도 요청하지 않습니다.

강사 화면의 **연결 종료**가 서버에 반영되면 코드는 더 이상 사용할 수 없습니다. 인터넷이 끊긴 상태에서 종료해 서버에 알리지 못하면 안내가 표시되고 TV에는 마지막 장이 남습니다. 강사 화면의 갱신이 끊긴 연결은 약 2시간 뒤 만료됩니다. 강사 화면을 새로 고치면 새 코드로 연결해 주세요. TV 화면만 새로 고친 경우에는 기존 주소의 코드로 다시 연결할 수 있습니다.

`living/`은 교재 원본 `에이전트AI_연수_조합강의`에서 `node 도구/공개용.cjs`로 만든 공개 사본입니다. 강사용 근거와 확인이 끝나지 않은 카드는 빠져 있습니다. 예정 시간은 리허설 전 어림입니다. 예전 `session1/`(1회차 통합본) · `deck/` · `modules/`는 이전 북마크를 위해 보존하며 첫 화면에서는 연결하지 않습니다.
