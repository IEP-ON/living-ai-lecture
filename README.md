## 프롬프터와 TV 발표

첫 화면에서 **프롬프터**를 누르면 큰 대본과 이전·다음 버튼이 나옵니다. 글자 크기(24~64px), 슬라이드 미리보기, 자동 스크롤 속도를 조절할 수 있습니다. 직접 스크롤하거나 장을 바꾸면 자동 스크롤은 멈춥니다. 화면 잠금 방지는 지원하는 브라우저에서만 작동합니다.

- **노트북 한 대 + TV:** 화면을 복제하지 말고 디스플레이를 **확장**으로 설정합니다. 프롬프터의 **TV 연결 → 슬라이드 창 열기**를 눌러 그 창만 TV로 옮기고 전체 화면으로 엽니다. 교안과 프롬프터는 노트북에 둡니다. 같은 기기의 창 연결은 인터넷 없이도 작동하지만 페이지와 자료는 미리 불러오거나 로컬 사본을 열어야 합니다.
- **태블릿 + TV에 연결한 노트북:** 태블릿에서 **프롬프터 → TV 연결 → 연결 코드 만들기**를 누릅니다. TV 쪽 컴퓨터에서 같은 강의의 **TV 연결 화면**을 열어 코드를 입력하거나, **TV 주소 복사**로 얻은 주소를 엽니다. TV에서 **전체 화면**을 한 번 누르면 됩니다. 강사 화면을 열어 둔 채 태블릿의 이전·다음으로 넘깁니다. TV 쪽에서는 장을 바꾸지 못합니다.
- 1부와 2부는 각각 연결합니다. 강사 화면을 새로 열거나 연결을 종료했다면 새 코드로 다시 연결합니다. TV 화면만 새로 고친 경우 주소의 코드로 재연결합니다.

기기 간 연결은 두 기기의 인터넷과 브라우저 WebRTC 지원이 필요합니다. PeerJS 공개 연결 서버 및 기본 STUN/TURN을 사용하므로 서버 상태나 학교망 정책에 따라 연결이 제한될 수 있습니다. 연결 상태와 재연결 버튼을 확인하고, 연결이 안 되면 위의 **노트북 한 대 + TV 확장 화면**을 사용합니다. 실제 현장 기기와 네트워크에서는 발표 전에 연결을 확인하세요.

원격으로 보내는 발표 데이터는 강의 식별자·장 번호·순서 번호이며 대본이나 강사용 근거를 보내지 않습니다. 연결 서버에는 연결용 식별자와 네트워크 정보가 전달됩니다. 코드가 있는 기기는 발표 화면에 접속할 수 있고, **연결 종료** 후 코드는 폐기됩니다. 별도의 카메라·마이크 권한은 요청하지 않습니다.

PeerJS **1.5.5**를 `js/vendor/peerjs.min.js`에 고정해 포함합니다([공식 문서](https://peerjs.com/docs/), [MIT 라이선스](deck/js/vendor/peerjs.LICENSE)). 파일 SHA-256: `7604d8c31bec4f134b0d15c2d80b1d095ea18af005354f439f14291fcd7b4168`.

이 저장소의 `deck/` · `modules/`는 강의 원본에서 `node 도구/공개용.cjs`로 만든 공개용 사본입니다. 강사용 근거와 확인이 끝나지 않은 카드는 빠져 있습니다. 예정 시간은 리허설 전 어림입니다.
